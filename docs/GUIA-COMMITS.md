# Guía de commits

Formato: `tipo(alcance): cambio específico con intención`, sin nombres de usuario en el mensaje. La autoría se conserva mediante la configuración real de Git.

Ver la [guía completa del docente](docs/09-GIT-ROLES-COMMITS.md).

Para este desarrollo individual, realizar un commit y su push después de terminar y verificar cada cambio concreto, conforme a la instrucción del responsable del proyecto. Esta instrucción sustituye la espera de revisión previa a la subida indicada en los prompts originales de implementación. No inventar revisores ni contribuciones.
